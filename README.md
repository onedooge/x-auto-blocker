# X Auto Blocker 🛡️

自动检测并屏蔽X（Twitter）上发布不当内容的账号。

## 功能

- ✅ 自动扫描时间线上的推文
- ✅ 关键词检测（支持中英文）
- ✅ **渐进式打击**：先隐藏推文，惯犯达到阈值后再升级屏蔽账号
- ✅ 自定义关键词（增删改）
- ✅ 白名单账号（永不隐藏/屏蔽）
- ✅ 关键词导出/导入备份
- ✅ 屏蔽 / 隐藏记录可查
- ✅ 统计已屏蔽数量
- ✅ 开关随时切换

---

## 安装方法（Chrome / Edge）

1. 下载并解压本插件文件夹
2. 打开浏览器，地址栏输入：
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
3. 右上角开启「**开发者模式**」
4. 点击「**加载已解压的扩展程序**」
5. 选择本文件夹（x-auto-blocker）
6. 安装完成 ✓

---

## 使用方法

1. 打开 x.com，登录账号
2. 点击浏览器右上角的插件图标
3. 确认状态显示「运行中」
4. 插件会自动扫描并处理不当推文

### 工作机制（渐进式打击）

```
推文命中关键词
    ↓
先在本地隐藏（display:none，不影响 X 服务端）
    ↓
同一账号 24 小时内反复触发
    ↓
触发次数达到阈值（默认 10 次）
    ↓
升级 → 调用 X 屏蔽 API，永久屏蔽该账号
```

| 动作 | 范围 | 可逆性 |
|------|------|--------|
| 🟡 隐藏推文 | 仅本地浏览器，X 服务端不知情 | 刷新即恢复 |
| 🔴 屏蔽账号 | 调用 X 真正的"屏蔽"功能 | 需在 X 设置中手动解除 |

阈值可在「设置」标签页调整（1–99）。

---

## 注意事项

- 自动屏蔽功能依赖X页面的DOM结构，如X更新页面可能需要调整选择器
- 建议先使用「仅隐藏推文」模式测试效果，确认无误后再开启自动屏蔽
- 关键词可在弹窗中随时增删
